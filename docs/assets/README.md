# Result Assets

The README embeds PNG files so GitHub mobile and phone viewers display the plots reliably.

SVG files are kept as editable vector sources. The PPK2 trace PNGs are regenerated by:

```bash
python benchmarks/generate_power_summaries.py --trace-dir /path/to/ppk2/csv_exports
```

The static summary PNGs are rendered from their SVG sources with:

```bash
rsvg-convert docs/assets/<name>.svg -o docs/assets/<name>.png
```
